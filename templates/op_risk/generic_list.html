Guía del Módulo: Matriz de Controles (Paso 3)

Aquí debe documentar las medidas de mitigación implementadas para reducir los riesgos identificados. Diseñe controles preventivos, detectivos o correctivos, asigne un responsable y evalúe su efectividad operativa.

  • Ejemplo Preventivo: Aprobación dual en el sistema para desembolsos mayores a S/ 10,000.
  • Ejemplo Detectivo: Cuadre de caja diario al cierre de la agencia y arqueos sorpresivos.
{% elif type == 'event' %}
Guía del Módulo: Registro de Eventos (Paso 4)

Capture incidentes reales, cuasi pérdidas, fraudes o fallas del sistema en este módulo. Es vital registrar la fecha, el impacto económico (monto) y la causa raíz para retroalimentar su Matriz de Riesgos.

  • Ejemplo de Pérdida: Faltante de S/ 500 en caja por error de conteo del cajero.
  • Ejemplo de Cuasi Pérdida: Intento de fraude con pagaré falso, detectado antes del desembolso (S/ 0 pérdida).
{% elif type == 'kri' %}
Guía del Módulo: KRIs y KPIs (Paso 5)

Gestione los Indicadores Clave de Riesgo (KRI). Defina umbrales, semáforos y alertas para monitorear tendencias antes de que un riesgo se materialice en una pérdida.

  • Ejemplo de KRI: Número de caídas del Core Financiero al mes (Límite: 2).
  • Ejemplo de KRI: Porcentaje de créditos aprobados con excepciones a la política (Límite: 5%).
{% elif type == 'plan' %}
Guía del Módulo: Planes de Acción (Paso 6)

Cuando un Riesgo Residual sea inaceptable o un control falle, cree un Plan de Acción. Defina compromisos claros, fechas límite de cumplimiento y asigne responsables.

  • Ejemplo de Acción: Capacitar a todo el personal de ventanilla en detección de billetes falsos.
  • Ejemplo de Acción: Implementar un firewall perimetral para proteger la base de datos de socios.
{% elif type == 'doc' %}
Guía del Módulo: Gestión Documental (Paso 7)

Respalde toda la gestión con evidencia. Suba manuales, normativas, y comprobantes de ejecución de controles o planes de acción.

  • Ejemplo de Documento: Manual de Políticas de Crédito V2.0 aprobado por el Consejo.
  • Ejemplo de Evidencia: Acta de arqueo de caja sorpresiva firmada (PDF).
{% elif type == 'capital' %}
Cálculo de Capital Operacional

Gestione el historial de requerimientos de patrimonio efectivo por riesgo operacional bajo Basilea / SBS.

{% else %}
Guía del Módulo: Matriz de Riesgos (Paso 2)

Levante y evalúe los riesgos inherentes de cada proceso de la Cooperativa. Defina qué puede salir mal, califique el Impacto/Probabilidad y use el Asistente IA (Copilot).

  • Ejemplo de Riesgo: Fraude interno en el otorgamiento de créditos por colusión de asesores.
  • Ejemplo de Riesgo: Robo de información confidencial de socios por ciberataque al servidor.
{% endif %}
